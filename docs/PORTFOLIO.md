## Interview explanation

We wanted to make the evidence behind disposal records visible. I worked with Biruk on a two-person prototype using AI coding assistance and an existing full-stack starter. The core engineering flow was photo upload, server-side image assessment, pending submission, human review and a persistent map record. Biruk helped refine the problem and presented. We received Bronze at the HKU station. Our demo used simulated points, so I distinguish demonstrated functionality from unvalidated demand and impact.
